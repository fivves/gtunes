# gTunes 1.1.8

gTunes 1.1.8 is The Responsive Release. The window now reflows to fit the size it is given instead of clipping.

## Highlights

- Reflow the window into layout tiers instead of clipping. Below half size gTunes drops to a compact layout: the track table tightens its columns, nav labels shorten, the player bar drops its wider furniture, and all four columns stay because there is still width for them.
- Give height its own rule. Short windows fold the sidebar's cover art and Next Up card away instead of pushing the bottom row of navigation out of view, which is what a small tiled window used to lose.
- The queue has exactly one way in at any size: the Next Up card in a tall window, and a Next Up row in the nav once the card is gone. The row shows the same upcoming count as the Next Up page.
- Half size and larger are untouched. That is the size that already looked right, so a width tier starts below it rather than at it.
- Support down to the eighth of the screen (466x503), fully compact with every control still reachable. Below that, clipping is acceptable.

## Notes

- The thresholds live in `src/ui/layout.rs` (`WIDTH_COMPACT_BELOW`, `WIDTH_NARROW_BELOW`, `WIDTH_TINY_BELOW`, `HEIGHT_SHORT_BELOW`, `HEIGHT_TINY_BELOW`). The classifier is pure and unit tested, so retuning a tier is a constant change.
- The height boundary has to sit above the full layout's own content minimum (494x913), or a window in between shows the full sidebar and loses its bottom bar. That gap was the bug.
- `GTUNES_LAYOUT_DEBUG=1` prints the measured size, the class, the per-class decisions and the content minimum to stderr, and puts the class in the window title. `GTUNES_LAYOUT_FORCE_WINDOW=961x494` opens at an exact size and `GTUNES_LAYOUT_FORCE_CLASS=full/short` pins a class. All of them are inert unless set.
- The repo ships the harness this was verified with: `measure-classes.sh` measures a tier's content minimum, `sweep-layout.sh` checks every realistic tile size against the class it lands in and calls out any that would not fit, and `verify-tiers.sh` with `gtwin.py` drives an isolated instance at exact sizes without touching a running one.
