# gTunes 1.1.6

gTunes 1.1.6 is a bug fix release for Discord Rich Presence.

## Highlights

- Stop Discord from showing a paused track for hours or days at a time. The app now reads the reply Discord sends back for every presence command, and it re-asserts the cleared state until it lands. Those replies used to go unread, and once that backlog grew the clear sent on pause was dropped, which left the last song on the profile until the app was closed.
- Keep a queued gapless handoff from advancing the app to the next track while playback is paused or stopped.
- Stop treating a dropped stream connection while paused as a playback failure, which could restart the track and republish it without user input.

## Notes

- A playing track is still published once per playback change and then left alone, so the elapsed timer Discord shows stays accurate. Only the cleared state is repeated.
- Reply handling means a rejected presence update is now visible in debug logs instead of failing silently.
