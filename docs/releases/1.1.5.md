# gTunes 1.1.5

gTunes 1.1.5 brings playback out of the desktop with Chromecast and UPnP/DLNA casting, adds a reorderable Next Up queue page, and rounds out the release with new appearance settings, Discord privacy controls, and a broad performance pass.

## Highlights

- Cast playback to Chromecast and UPnP/DLNA devices. The new cast button in the player bar scans the local network, shows discovered devices grouped by type, and keeps transport controls, seeking, and the on-screen timecode in sync with the device. Playback hands off at the current position in both directions, radio stations cast too, and a right-click on the cast button instantly disconnects or reconnects to the last device.
- Reorder the queue from the new Next Up page. The sidebar queue preview now links to a full page showing up to 50 upcoming tracks with smooth drag-and-drop reordering.
- Control how gTunes looks and feels. A new Animations switch turns UI animation on or off for lower-powered machines, and a Font Style setting switches the interface between the default and monospace fonts.
- Take control of Discord Rich Presence. A new settings switch turns the integration off entirely, album art is only mirrored for presence while a Discord connection is actually established, and private Jellyfin artwork URLs are never sent to Discord.

## Fixes and Refinements

- Fixed spurious auto-play: a track paused for 20-30 minutes no longer resumes on its own when the streaming connection drops.
- Fixed type-to-jump stealing keystrokes from the radio station form fields, which made it impossible to type station names, URLs, or icons that matched library items.
- Fixed the cast device list going stale after devices left or joined the network.
- Playing and queueing tracks no longer clones the full track list, sorting no longer allocates per comparison, and the player bar no longer runs a per-frame layout callback, keeping large libraries responsive.
- Playback snapshot writes are throttled while scrubbing the waveform, and a popover leak on the radio page is fixed.
- Double-click the sidebar navigation to play something random from the current page.
- A loading spinner on the play button now shows when a track is buffering.
- Collection artwork fades in instead of popping, artwork downloads share one HTTP connection pool, and page navigation uses directional slide transitions.
- The interface codebase was split from a single 10k-line window module into focused modules per concern, and previously suppressed dead code was removed, making future releases easier to verify.
